# only stack proven to complete a handshake on all three device types.

# instead of carrying a hardcoded address that a DHCP change would break.
#
# wolfssl is PINNED, not a floor: PyPI ships it source-only (no wheels), so
# every install compiles the bundled wolfSSL C library, and an API change in
# a newer release would only surface after deployment. 5.9.2.post0 is the
# version soaked on hardware and observed negotiating
# TLS_AES_256_GCM_SHA384 <-> the NMU's TLS_AES_128_GCM_SHA256
# (evidence/2026-08-29_amu_cipher_observed.md).
